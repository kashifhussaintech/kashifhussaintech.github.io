# Kashif Hussain — Portfolio

Static portfolio website (HTML/CSS/JavaScript).

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder.

## Deploy
Push this folder to a GitHub repository. In Netlify, import the GitHub repository, set the publish directory to `.` and leave the build command blank.

## Content
Portfolio content is aligned with the AI/ML internship resume. Work in progress is labelled clearly.
